# Upstream references

This is an independent coordination skill. It refers to the following projects and practices; their source code and skill bodies are not bundled:

- [OpenSpec](https://github.com/Fission-AI/OpenSpec): specification artifacts and change lifecycle. The inspected source is MIT-licensed, copyright OpenSpec Contributors.
- [Superpowers](https://github.com/obra/superpowers): discovery, planning, TDD, debugging, review, and verification workflows. The inspected source is MIT-licensed, copyright Jesse Vincent.
- [Matt Pocock's skills](https://github.com/mattpocock/skills): domain-modeling and agent-instruction resources. The inspected source is MIT-licensed, copyright Matt Pocock. Domain-modeling is one possible DDD workflow, not a required universal implementation.

Upstream projects retain their own names, copyright, licenses, installation procedures, and release schedules. Refer to their repositories for current requirements. This repository makes no affiliation or endorsement claim.

The original coordination text and standalone loan example here are provided under this repository's MIT license. No upstream dependency is downloaded or installed by the validator.
